# GitHub Farm 交付与后续计划

## 当前交付

当前版本已在 GitHub Pages 上交付。任意公开仓库可生成静态农场，支持分享、切换成长档位、查看地点和下载 PNG。Actions 每天更新本项目的 README 农场图，其他仓库可按同一方式配置。[打开生成器](https://yeatsliao.github.io/github-farm/) · [部署指南](DEPLOYMENT.md)

## 已完成 · 岸线、木台与围栏

- 岸线用不规则的湿土、浅滩、深水过渡。零散碎石、芦苇和植被簇顺岸分布，留出通往水边的路径。
- 过水码头从岸上的路接入，木台有统一的板缝、端板与支脚。门前石块保留清楚的层次。
- 围栏以连续线段布置，共用角柱并给小路让出入口。收获台、篮子与箱子靠作业区摆放。
- 编译图集时清理小块游离像素。按浅草、深草、泥土和水边检查轮廓，尤其关注素材交界。
- 固定镜头对比 0、25、100 和 300 Stars。验收岸线、收获台、围栏入口的放大图以及 README 宽度下的识别度。

## 已完成 · 菜园和牧场的地块与通道

- 庭院菜园沿地块布置围栏，入口朝向小路，晾晒区接近菜地和院子。
- 谷仓牧场沿实际边界围合，鸡在陆地活动的位置和鸭子的浅水区各自明确，牧场扩建从预留缺口接入。
- 建筑、田地和围栏参与道路转弯的避让。测试覆盖扩建路连通性、围栏入口、水陆摆件和作物占地。

## 0–100 Stars 起步作业区

- **庭院菜园**开局有育苗盘和浇水壶，25 Stars 架起番茄竹架，100 Stars 在田埂的小路旁开工具棚。
- **溪边果园**开局有采果梯和空果筐，25 Stars 在分拣台旁添上满果筐，100 Stars 接入绿顶果酱棚。
- **谷仓牧场**开局有饮水槽，25 Stars 添草捆和鸡舍旁的蛋篮，100 Stars 接入储草棚。

[三种农场的 0、25、100 Stars 对照](https://yeatsliao.github.io/github-farm/farm-materials.png)

## 200–300 Stars 扩建

- **庭院菜园**在 200 Stars 接通出货区，设带篷柜台、手推车和待种的新田。300 Stars 新田长出作物，柜台旁出现装好的菜箱。
- **溪边果园**在 200 Stars 把分拣台和旧码头接到岸边交接区，增设果箱架和拖车。300 Stars 给旧码头添系船桩，主屋另一侧扩种果树。
- **谷仓牧场**在 200 Stars 接入第二座鸡舍，沿门前的路设分拣台和产蛋箱。300 Stars 在新增的围栏入口立门柱，扩展鸡的活动范围。

[三种农场的 100、200、300 Stars 同镜头对照](https://yeatsliao.github.io/github-farm/farm-expansions.png)

## 400–1,000 Stars 作业区

- 菜园补清洗台、装箱和出货货架，果园沿东侧果树接榨果台和装瓶区，牧场沿第二座鸡舍补水槽、饲料和装蛋区。
- 每 100 Stars 有新作业物件。保持镜头固定做 300–1,000 Stars 对照，单独以 320 像素宽检查 0、5、25、100、300 Stars 的地块边缘和入口。
- 公开 API 限流时，网页用同一个仓库 24 小时内的保存数据生成预览与 PNG，并保留重试入口。

[三种农场的 300–1,000 Stars 同镜头对照](https://yeatsliao.github.io/github-farm/farm-workyards.png)
