# GitHub Farm - PRD 产品需求文档

> 把 GitHub 贡献数据可视化为一座星露谷风格的像素农场

---

## 1. 项目概述

| 项目 | 说明 |
|------|------|
| 名称 | GitHub Farm |
| 定位 | GitHub 贡献可视化开源工具 |
| 风格 | 星露谷物语像素风 |
| 输出 | SVG（可嵌入 GitHub Profile README） |
| 仓库 | https://github.com/YeatsLiao/github-farm |
| 作者 | YeatsLiao |
| 许可证 | MIT |

## 2. 核心功能

### 2.1 贡献数据 → 农场元素映射

| GitHub 数据 | 农场元素 | 映射规则 |
|---|---|---|
| 每日 Commit 数 | 作物生长阶段 | 0=空地, 1=种子, 2=嫩芽, 3=成长, 4+=丰收 |
| 连续提交天数 | 建筑解锁 | 7天=围栏, 15天=水井, 20天=谷仓, 30天=稻草人, 40天=风车 |
| 编程语言分布 | 树木种类 | Java=橡树, Python=柳树, JS=枫树, Go=松树 |
| PR 合并数 | 动物出现 | 鸡、牛、猫、狗 |
| Issue 参与数 | 花朵装饰 | 点缀农场 |
| 总贡献量 | 季节变化 | 春/夏/秋/冬视觉主题 |

### 2.2 输出格式

- **SVG**：矢量格式，可嵌入任何 Markdown
- **PNG**：位图格式，用于社交媒体分享
- 默认尺寸：800x400px（可配置）

### 2.3 使用方式

1. **GitHub Action**（推荐）：自动每日更新，输出到仓库
2. **CLI 本地运行**：`npm run build` 生成 SVG
3. **在线预览**：`npm run dev` 启动开发服务器

## 3. 用户场景

### 场景 1：开发者展示个人主页
- 用户在 GitHub Profile README 中嵌入农场 SVG
- 访客看到一座生动的像素农场，直观了解贡献活跃度

### 场景 2：团队贡献可视化
- 团队仓库展示团队整体贡献的农场

### 场景 3：年度总结
- 年底生成年度农场全景图

## 4. 非功能需求

| 需求 | 指标 |
|------|------|
| 性能 | SVG 生成 < 5 秒 |
| 兼容性 | Node.js >= 18 |
| 可维护性 | 模块化架构，主题可插拔 |
| 隐私 | 仅读取公开贡献数据 |

## 6. 竞品分析

| 工具 | 风格 | 差异点 |
|------|------|--------|
| kodama | 日式盆栽 SVG | 我们做农场，更丰富的场景元素 |
| github-contributions-chart | 热力图变体 | 我们做场景化，不只是图表 |
| pixel-profile | 像素资料卡 | 我们做完整农场场景 |
| isometric-contributions | 3D 等距像素 | 我们做 2D 俯视角农场 |

## 7. 技术选型

- **运行时**：Node.js（ES Module）
- **渲染**：SVG（纯字符串模板，无外部依赖）
- **数据源**：GitHub GraphQL API
- **自动化**：GitHub Actions
- **素材**：AI 生成像素风精灵图 + 手绘调整
