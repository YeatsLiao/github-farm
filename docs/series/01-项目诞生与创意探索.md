# 01 - 项目诞生与创意探索

> 从 GitHub API 工具讨论到星露谷农场可视化的诞生

## 背景

2026 年 8 月 3 日，在讨论 GitHub 开发者标识和 API 工具时，提出了"贡献可视化"的想法。

最初考虑的方向是 **Stars 自动同步工具**，但调研发现已有成熟方案：

| 工具 | Stars | 功能 |
|------|-------|------|
| GithubStarsManager | 3.2K | GitHub Stars 分类展示与同步 |
| isometric-contributions | 热门 | 3D 等距像素贡献图 |
| github-contributions-chart | 热门 | 热力图变体 |
| pixel-profile | 热门 | 像素风格资料卡 |

**结论**：Stars 同步工具已有成熟方案，不做重复造轮子。

## 创意探索：6 个可视化方向

为了找到差异化方向，提出了 6 个贡献可视化方案，并制作了 Canvas 概念 Demo：

### 方向对比

| 方向 | 风格 | 评价 | 最终决策 |
|------|------|------|----------|
| 星露谷农场 | 像素风 | 接地气，传播性强，与 kodama 形成差异化 | **选定** |
| 像素城市 | 都市风 | 视觉冲击力强，但开发量大 | 备选 |
| 深海水族馆 | 治愈系 | 差异化好，但场景较单一 | 备选 |
| 星际宇宙 | 科幻风 | 浪漫，但不够独特 | 放弃 |
| 登山探险 | 励志风 | 励志，但场景较单一 | 放弃 |
| 像素冒险 | 极客风 | 有趣，但受众较窄 | 放弃 |

### 选定星露谷农场的理由

1. **差异化**：与 kodama（日式盆栽 SVG）形成明显区分
2. **传播性**：星露谷是知名游戏，像素风有天然吸引力
3. **扩展性**：农场场景可以容纳多种元素（作物/建筑/动物/树木）
4. **映射自然**：贡献数据与农场元素的映射关系直观

## Canvas Demo 验证

制作了 `contrib-viz-demo.html`（位于 yeatsliao.github.io 项目），用 Canvas 快速验证了 6 个方向的视觉效果。

**关键发现**：Canvas 代码绘制的像素风效果粗糙，无法匹配真实像素艺术素材的质感。

**决策**：放弃 Canvas 代码绘制，改用 AI 生成真实像素风素材 + SVG 渲染引擎组合方案。
