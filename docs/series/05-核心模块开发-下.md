# 05 - 核心模块开发（下）：布局算法与渲染引擎

> farm-layout.js、renderer.js、index.js 的实现过程

## farm-layout.js - 农场布局算法

### 设计思路

将 FarmData 转换为带坐标的场景元素列表（SceneElement[]），每个元素包含类型、位置、尺寸等属性。

### 6 个计算函数

| 函数 | 输入 | 输出 | 说明 |
|------|------|------|------|
| calculateCrops(weeks) | 贡献周数据 | 作物网格 | 4x8=32 个作物位置 |
| calculateTrees(languages) | 语言数据 | 树木位置 | Top 语言→树木 |
| calculateBuildings(streak) | 连续提交 | 建筑位置 | 达标则放置 |
| calculateAnimals(totalPRs, season) | PR 数+季节 | 动物位置 | 最多 8 只 |
| calculateDecorations(totalIssues, season) | Issue 数+季节 | 花朵位置 | 最多 12 朵 |
| calculateCharacter() | 无 | 角色位置 | 固定位置 |

### buildScene() 主函数

按顺序调用 6 个计算函数，合并为完整的场景元素数组。

**测试结果**（mock 数据）：
- 32 作物 + 2 树 + 4 建筑 + 5 动物 + 8 装饰 + 1 角色 = **52 个元素**

## renderer.js - SVG 渲染引擎

### 设计思路

使用纯字符串模板生成 SVG，无需外部依赖。按类型分层渲染，确保元素遮挡关系正确。

### 渲染顺序（从底到顶）

1. **背景层**：渐变天空 + 草地
2. **作物层**：土壤方块 + 作物椭圆
3. **树木层**：树干 + 树冠 + 果实
4. **建筑层**：建筑方块 + 标签文字
5. **动物层**：椭圆身体 + 眼睛
6. **装饰层**：花朵圆圈
7. **角色层**：帽子 + 身体 + 腿

### 6 个渲染函数

每个函数接收 SceneElement + 画布尺寸，返回 SVG 片段字符串。

## index.js - 主入口

### 设计思路

串联所有模块，提供 CLI 和可编程 API 两种使用方式。

### CLI 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| --username | GitHub 用户名 | YeatsLiao |
| --token | GitHub PAT | 环境变量 GITHUB_TOKEN |
| --output | 输出文件路径 | dist/farm.svg |
| --width | SVG 宽度 | 800 |
| --height | SVG 高度 | 400 |
| --mock | 使用模拟数据 | false |
| --help | 显示帮助 | - |

### 智能降级

无 token 时自动降级为 mock 模式，方便开发调试。
