# 04 - 核心模块开发（上）：数据层与主题配置

> fetcher.js 和 themes/stardew.js 的实现过程

## fetcher.js - 数据获取层

### 设计思路

使用 GitHub GraphQL API 的 `contributionCalendar` 查询获取用户贡献数据，解析为结构化的 `FarmData` 对象。

### 核心功能

1. **GraphQL 查询**：获取贡献日历、仓库列表、PR、Issue
2. **贡献等级映射**：0=空, 1-3=level1, 4-6=level2, 7-10=level3, 11+=level4
3. **连续提交计算**：current streak 和 longest streak
4. **语言统计**：Top 8 编程语言及占比
5. **季节判断**：根据当前月份返回 spring/summer/autumn/winter
6. **Mock 数据**：`generateMockData()` 用于开发调试

### FarmData 数据结构

```javascript
{
  totalContributions: number,
  weeks: [{ days: [{ count, date, weekday, level }] }],
  streak: { current, longest },
  totalPRs, totalIssues, totalRepos,
  languages: [{ name, color, count }],
  season: 'spring'|'summer'|'autumn'|'winter'
}
```

## themes/stardew.js - 星露谷主题配置

### 设计思路

将星露谷的视觉风格抽象为可配置的常量，使渲染引擎可以灵活调整外观。

### 导出配置

| 配置项 | 说明 |
|--------|------|
| CROP_STAGES | 作物 5 阶段（empty/seed/sprout/growing/harvest） |
| LANGUAGE_TREES | 10+ 编程语言→树木类型映射 |
| SEASON_THEMES | 四季配色方案（天空/草地/土壤/花朵/动物） |
| BUILDING_THRESHOLDS | 建筑解锁阈值（天数要求） |
| FARM_CONFIG | 农场布局参数（网格尺寸、区域百分比） |
| PALETTE | 颜色调色板 |
| SPRITE_SIZES | 精灵尺寸配置 |
