# 02 - AI 素材生成与项目初始化

> 用 AI 生成像素风素材，搭建项目骨架

## AI 素材生成

使用 AI 生成了 4 张像素风素材，作为渲染引擎的视觉基础：

### 素材清单

| 文件 | 说明 | 用途 |
|------|------|------|
| `assets/scenes/concept-art.png` | 星露谷风格农场概念图 | 整体风格参考 |
| `assets/sprites/farm-spritesheet.png` | 精灵素材表（作物/建筑/动物/树木） | 渲染素材来源 |
| `assets/scenes/farm-bg.png` | 农场地面背景瓦片 | 场景底层背景 |
| `assets/sprites/farmer.png` | 农夫角色像素图 | 场景角色元素 |

### 为什么用 AI 生成素材

1. **快速原型**：降低启动成本，无需等待设计师
2. **质量可控**：AI 生成的像素风质量已足够作为基础
3. **后续优化**：可以找设计师优化或接受社区贡献

## 项目初始化

### 仓库创建

- 仓库地址：https://github.com/YeatsLiao/github-farm
- 许可证：MIT
- Node.js 版本要求：>= 18.0.0

### 初始文件结构

```
github-farm/
├── assets/
│   ├── sprites/        # 像素精灵图
│   └── scenes/         # 场景背景
├── src/                # 源代码（后续填充）
├── .github/
│   └── workflows/
│       └── farm.yml    # GitHub Action 自动更新
├── package.json        # ES Module, Node >= 18
├── LICENSE             # MIT
── README.md           # 项目说明
```

### GitHub Action 工作流

配置了每日自动更新的工作流（`.github/workflows/farm.yml`）：

- **触发方式**：每日 cron + 手动触发 + push 触发
- **功能**：拉取贡献数据 → 生成 SVG → 自动 commit & push
- **密钥**：使用 `GITHUB_TOKEN` 环境变量
