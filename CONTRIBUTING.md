# Contributing to GitHub Farm

🌱 Thanks for your interest in contributing! This project is early-stage and every bit of help counts.

## How to Contribute

### 🐛 Report Bugs
Found something broken? [Open an issue](https://github.com/YeatsLiao/github-farm/issues/new) with:
- What you did
- What happened
- What you expected

### 💡 Suggest Features
Have an idea to make this better? [Open an issue](https://github.com/YeatsLiao/github-farm/issues/new) and let's discuss!

### 🔧 Submit Code
1. Fork the repo
2. Create a branch: `git checkout -b feature/your-feature`
3. Make your changes
4. Test locally: `npm run dev`
5. Commit: `git commit -m "feat: add your feature"`
6. Push and create a PR

### 🎨 Improve Pixel Art
We need better sprites! Check `assets/sprites/` and help us create:
- More crop varieties
- Seasonal themes (winter, autumn)
- Better animal sprites
- Decorations and buildings

### 📝 Improve Documentation
- Fix typos or unclear explanations
- Add examples
- Translate to other languages

## Development Setup

```bash
npm install
npm run dev      # Start dev server with mock data
```

For real GitHub data:
```bash
# Windows PowerShell
$env:GITHUB_TOKEN="ghp_your_token"; npm run dev

# macOS / Linux
GITHUB_TOKEN=ghp_your_token npm run dev
```

## Code Style

- Use ES6+ syntax
- Keep functions small and focused
- Add comments for complex logic
- Follow existing naming conventions

## Questions?

Feel free to [open an issue](https://github.com/YeatsLiao/github-farm/issues/new) or reach out. We're here to help!
